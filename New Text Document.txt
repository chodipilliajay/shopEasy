### Run it

After extracting:

```bash
npm install
npm run dev
```

For publishing:

```bash
npm run build
```

The generated `dist` folder can then be deployed as a Vite static website.

### Important for your interview/project explanation

This version is intentionally **server-independent**. So you can demonstrate the complete user journey even if MongoDB, Express, Cloudinary, or Razorpay aren't running.

For example, you can demonstrate:

**Register → Login → Browse Products → Add to Cart → Update Quantity → Checkout → Fake Razorpay Payment → Order Created → Track Order**

And then demonstrate:

**Admin Login → Admin Dashboard → Add Product → Delete Product → View Users → View Orders**

When you later want the **real MERN version**, the UI can be connected to your existing Express/MongoDB backend by replacing the localStorage operations with your API calls.
